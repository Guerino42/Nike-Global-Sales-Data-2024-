# Analisi delle Vendite Nike (2024)

## Descrizione del Progetto  
Questo progetto analizza il dataset delle vendite **globali di Nike nel 2024**, fornendo insight sulle performance di mercato.  

## Tecnologie Utilizzate
- SQL (phpMyAdmin): Gestione e analisi del dataset tramite query SQL.
- Power BI: Creazione di dashboard interattivi e grafici per una comunicazione efficace dei risultati.

## Dataset
Questo set di dati contiene informazioni dettagliate sulle vendite mensili, tra cui:
- Regioni: Cina, Giappone, Corea del Sud, India, Sud-est asiatico, America, Europa.
- Categorie: Calzature, Abbigliamento e Attrezzature, con varie sottocategorie e linee di prodotto.
- Metriche: unità vendute, ricavi (USD), prezzi al dettaglio e percentuali di vendita online.

**Link: https://www.kaggle.com/datasets/ayushcx/nike-global-sales-data-2024**
